# ProCloud Documentation Site

This branch (`docs`) hosts the official **ProCloud Documentation** published via **GitHub Pages**.

## Live Documentation
Visit the live documentation at: **`https://sanjeevsenapati.github.io/procloud/`**

## GitHub Pages Configuration
To serve this documentation on GitHub Pages:
1. Go to your repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Select branch **`docs`** and folder **`/ (root)`**.
4. Click **Save**. GitHub Pages will automatically publish the site.

## Architecture
- **Single-Node Sovereign Cloud**: Built on Linux, Podman, systemd Quadlet, Netavark, and SQLite WAL.
- **Pure Static HTML & CSS**: Zero third-party CDN dependencies; loads instantly and works offline.
- **Design System**: ProGit White & Light Blue theme (`#f0f6ff`, `#ffffff`, `#2563eb`, `#0f172a`).
